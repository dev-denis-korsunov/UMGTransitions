## Назначение

UMGTransitions — Blueprint-плагин для анимации свойств отдельных виджетов и выбранных групп.

| Задача поддержки UI | Подход |
| --- | --- |
| Повторять одинаковое движение в разных Widget Blueprint | Параметризованная функция или макрос |
| Менять количество детей | Выборка через Composer |
| Поддерживать согласованные duration/характер движения | Общие параметры паттерна |
| Анимировать динамическое число или материал | Numeric value и property/material binding |
| Работать с разными состояниями вёрстки | From/To относительно данных конкретного контекста |

Widget Animation подходит для авторской последовательности с timeline. Для переиспользуемых переходов поддержка отдельных timeline в каждом виджете создаёт дополнительные места правок.

## Принципы

| Часть | Ответственность |
| --- | --- |
| Create / From / Easing / Spring | Собрать копию Transition |
| Add / Add Array / Async | Передать её системе |
| Widget Property | Применить вычисленное значение |
| Composer | Выбрать участников и порядок |
| Events | Передать value внешнему потребителю |

Pure-функции не запускают transition, но сами выполняют код при вычислении Blueprint-графа. Общую конфигурацию удобно выносить в функцию; макрос позволяет повторить граф запуска с execution pins. Не рассчитывайте, что pure-вызов с несколькими потребителями выполнится только один раз.

## Производительность и тестирование

| Принятое решение | Основание | Практический вывод |
| --- | --- | --- |
| Плотные массивы transition/spring | Storage experiments; 500 TArray spring 4.212 против sparse 4.670 мкс/кадр | Чинить связи после swap, сохранять плотность |
| Разделение lifecycle/update | 100 lifecycle после cleanup 0.489 против Updated 26.633 мкс/кадр без binding | Подключать Updated только потребителям промежуточного value |
| Ограничение event frequency | 100 Updated: 28.333 → 15.140 мкс/кадр при 0 → 0.033 с | Частота событий — существенный регулятор бюджета |
| Keyed FIFO | 500 linear handoff: 3324.742 → 380.379 мкс/tick | Очередь должна масштабироваться по свойствам |

Это результаты разных исторических серий, не одна сравнительная таблица алгоритмов. Конфигурации, общий A/B и размеры: [Тестирование](Testing.md#общий-ab-системы); локальные причины — в соответствующих доменах.

# Документация UMGTransitions

UMGTransitions — набор Blueprint-инструментов для компактных, переиспользуемых анимаций свойств UMG-виджетов. Transition описывается чистыми функциями, а затем запускается системой: это отделяет художественное решение от момента исполнения.
